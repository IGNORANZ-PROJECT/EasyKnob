大切な注意事項

EasyKnobを使う前に、プライバシーと音量に関する注意を確認してください。

  • マイク音声はサーバーへ送信しません。音声処理はブラウザ内で行われます。
  • マイク権限が必要です。初回はONを押すまで許可画面は表示されません。ONを押した後、ブラウザのマイク使用を許可してください。
  • 音量に注意してください。ヘッドホンやスピーカーの音量を低めにしてから起動してください。
  • 外部アプリ側の設定も影響します。Discord、OBS、VRChat、VB-CABLE、BlackHoleなどの設定によって、音質や遅延が変わります。
  • 利用は自己責任です。聴覚、機器、配信、通話、OSやブラウザ設定に関する問題について、作者およびIGNORANZ PROJECTは責任を負いません。

この注意事項は初回のみ表示されます。詳しい使い方は「初めての方へ」とREADMEを確認してください。

ワンクリックで簡単設定

触らずに音を作る

用途に近いボタンを押すだけで、ノブ、ON/OFF、REVERB詳細をまとめて反映します。反映後に必要なところだけ微調整してください。

設定

ノブを無効化すると、メイン画面から隠し、音声処理から外します。

REVERB 詳細

REVERB成分だけにかかるEQです。原音にはかかりません。

HOW TO USE

初めての方へ

最初の1回だけ

音の通り道を追加する

EasyKnobの声をVRChatやDiscordへ渡すために使います。物理的なケーブルは必要ありません。

  1. 1VB-CABLEを入れる公式ダウンロードを開く ↗
  2. 2ZIPを展開してインストールVBCABLE_Setup_x64.exeを右クリック → 管理者として実行 → Install Driver → PCを再起動
  3. 3EasyKnobのOutputCABLE Inputを選ぶ
  4. 4VRChat・DiscordのマイクCABLE Outputを選ぶ

Outputに「CABLE Input」が出たら準備完了

  1. 1BlackHole 2chを入れる公式ダウンロードを開く ↗
  2. 2ダウンロードしたパッケージを開く画面の案内どおりインストールし、Chromeと使用するアプリを開き直す
  3. 3EasyKnobのOutputBlackHole 2chを選ぶ
  4. 4VRChat・DiscordのマイクBlackHole 2chを選ぶ

Outputに「BlackHole 2ch」が出たら準備完了

音楽が急にこもる時Bluetoothイヤホンは聴くためだけに使い、InputはPC内蔵マイクかUSBマイクを選びます。

使い方を選ぶ

VRCHATBGMは使いません
  1. 1Outputを選ぶCABLE InputまたはBlackHole
  2. 2ONにする初回だけマイクを許可
  3. 3VRChatへ接続入力をCABLE OutputまたはBlackHoleに設定
  4. 4ワールドで同期カラオケ音源の遅延はワールド側で調整
ワールド音源→そのまま聴く+EasyKnobの声
PC AUDIO自分は遅延なしで聴きます
  1. 1音源を再生イヤホンで動画・アプリをそのまま聴く
  2. 2EasyKnobをONBGMの「音源を選ぶ」から音声を共有
  3. 3出力を合わせるSYNCで声とBGM、VOICEとBGMで音量を調整
  4. 4配信へ出すスピーカーまたは仮想ケーブルへまとめて出力
元音源→イヤホン／声+BGM→配信

元音源とEasyKnobのOutputを同じ機器で聴くと二重に聞こえます。

VOICE CHAT声だけを送ります
  1. 1Outputを選ぶCABLE InputまたはBlackHole
  2. 2ワンクリック設定「普通に話したい」などを選ぶ
  3. 3ONにするBGMはOFFのまま使用
  4. 4通話アプリへ接続入力を仮想オーディオに設定

ワンクリック設定

用途を選ぶだけで音を作ります。

MY PRESET

自分用の3枠。選択中の設定は自動保存されます。

音が出ない時

Chrome / Edgeを使い、マイクを許可してください。仮想オーディオがOutputに出ない場合は、インストール後にPCまたはアプリを再起動します。
